# EPI LAB

EPI LAB is an independent research organization working in epidemiology, environmental and occupational health, and cancer prevention. We treat reproducibility as part of the method: analysis code, protocols and codebooks are versioned and open wherever participant privacy allows.

## Research areas

Epidemiologic study design and analysis, environmental and occupational health, cancer prevention, and reproducible public-health research.

## How we work

Each study repository starts from a common template with a protocol, codebook, analysis scripts and output folders. Raw and identifiable data are never committed; only de-identified or synthetic data are shared publicly. Releases are archived with a DOI so that published results can be traced to the exact code that produced them.
